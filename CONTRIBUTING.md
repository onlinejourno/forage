# Contributing

Thank you for being here. This is **newsroom technology, open-sourced by a journalist** — and the whole point is that you don't have to be a news-org engineer to build for journalism. If you write code and care about how journalism reaches readers, you're exactly who this is for.

A small, deliberately-open tool from [OnlineJourno](https://onlinejourno.com), MIT-licensed — a gift to the commons.

## How to contribute

1. Fork the repo and create a branch.
2. Make a focused change; match the surrounding style.
3. Run the checks (see the README).
4. Open a pull request saying *what* and *why*. Screenshots help for the dashboard.

Small PRs land faster. For anything big, open an issue first so we can agree the shape.

## Good first issues

- **Add a crawler / AI-bot user-agent pattern** — the bots that matter keep changing (GPTBot, PerplexityBot, Google-Extended, …); help keep the list current.
- **Improve a plain-English fix** — the tool's value is translating a crawl problem into *what to ask the dev team*. Sharpen one of those explanations for editors.
- **Add a site-structure check** — a new way structure quietly hurts discoverability (orphan sections, sitemap gaps, depth, internal-link starvation).
- **Add tests** — for the log parser or the sitemap parser.
- **Accessibility / copy** on the web dashboard — it's meant for non-technical editors.

## A note on pace

Maintained by one person (a journalist, not a full-time engineer), so reviews are light-touch and roughly weekly — not instant. Please be patient and kind; I will be too.

## Conduct

Be decent. Assume good faith. We're here to build something useful for journalism, together.
